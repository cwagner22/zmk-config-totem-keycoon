TOTEM pointer cheatsheet

Launch

nav+Hneru grid (= Hyper+H; also V-hold+H anywhere, or ⌘⌃⌥⇧H on any keyboard)
nav+Ytoggle firmware mouse mode

Grid (neru)

lettersselect cell — bands qwert asdfg cvbnm yuiop hjkl; — 3rd pick auto-clicks & exits
RET / BSPCleft / right click, exit
space-hold + RETshift+click, exit (hold space a beat first)
tab-hold + RETcmd+click, exit
Tab tapundo one grid level
space-hold + e s d fscroll without closing the grid; t/g page
,switch to scroll mode
Esccancel

Scroll mode (neru)

e s d f tapscroll step up/left/down/right  (holding s/d/f gives mods, not repeats)
space-hold + e s d fcontinuous scroll
t / gpage up / down
clickssame as grid: RET, BSPC, space+RET, tab+RET
,back to the grid
Escdone

Mouse mode (firmware, toggled)

e s d fmove (ramps up while held)
esc-thumbtap = exit · hold = precise (slow) move
space-thumb holdscroll on e s d f, pages on t/g · + right-thumb click = click and stay
tab-thumb holdfast move
RET / BSPC / DELleft / right / middle click — all exit to base
right home rowplain ⇧ ⌘ ⌥ ⌃ for modified clicks/scroll
z / xdrag grab / drop (lock the button, both hands free)

If the pointer acts frozen

stuck mouse buttonmouse mode → x, or neru action left_click --state up in a terminal
