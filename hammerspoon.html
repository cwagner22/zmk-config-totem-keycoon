Window mode — Meh+W toggles (Hammerspoon, ~/.hammerspoon/windows-position.lua)

A modal: press Meh+W once to enter, everything below then works with no modifier until you press Esc (or Meh+W again) to exit. z, Shift+z, and n exit on their own as soon as they fire — they're one-shot. e s d f g leave the mode running, since resizing/fullscreen-cycling is meant to be repeated. An on-screen alert stays up the whole time as a reminder you're in it.

On the Totem, Meh is the home-row hold on , (or C) — ctrl+alt+shift, no cmd. Not Ctrl+Alt+W: that's Wispr Flow's dictation trigger (totem.keymap:373). Not Hyper (V/M hold): Hyper+H is already the neru grid, and macOS's own Caps-Lock Hyper is a separate, fully-claimed namespace of app launchers (Karabiner). Meh was free — totem.keymap earmarks it for exactly this ("no app claims these, so they are safe for global hotkeys"). Nothing below is bound outside the mode — that's the point: it used to be bare Ctrl+E/S/D/F/G and Ctrl+Alt+D/E/G all the time, which shadowed normal app shortcuts (Ctrl+S=save, Ctrl+Alt+D=duplicate tab, etc).

ssnap left, repeat to cycle width 1/2 → 1/3 → 2/3
fsnap right, same cycle
esnap top, repeat to cycle height 1/2 → 1/3 → 2/3
dsnap bottom, same cycle
s + f heldfull width
e + d heldfull height
gcenter, repeat to cycle size 100% → 133% → 200%
z (one-shot)re-maximize the focused app (no-op if it isn't in the fixed app list below)
Shift+z (one-shot)re-maximize every app in the list
n (one-shot)send focused window to the other screen, keeping relative size/position

e s d f are in the same physical positions as the nav layer's arrows (e=up, s=left, d=down, f=right), not literal hjkl or arrow keys.

Fixed app list (for z / Shift+z)

Claude, VS Code, Notion, Cursor, Edge, Chrome, Brave, Firefox Dev Edition — maximized in place, never moved to a different screen. Also auto-applied on monitor plug/unplug (~2s after the screen settles) and on Hammerspoon reload.

Not Ctrl+Down/Ctrl+Up for this: macOS owns those (App Exposé / Mission Control) and swallows them before Hammerspoon sees the event — same reason the mode needs its own toggle key rather than reusing an arrow combo.
