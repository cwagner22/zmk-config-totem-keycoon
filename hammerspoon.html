Window mode — Meh+W toggles (Hammerspoon, ~/.hammerspoon/windows-position.lua)

Meh = hold , or C (ctrl+alt+shift, no cmd). Esc or Meh+W exits. g, Shift+g, and the arrows exit automatically after firing; e s d f c stay in the mode so repeating them cycles sizes.

ssnap left, repeat to cycle width 1/2 → 1/3 → 2/3
fsnap right, same cycle
esnap top, repeat to cycle height 1/2 → 1/3 → 2/3
dsnap bottom, same cycle
s + f heldfull width
e + d heldfull height
ccenter, repeat to cycle size 100% → 133% → 200%
gfull size — fills the screen, still an ordinary window
Shift+gmacOS native full screen (separate Space)
↑re-apply the focused app's configured layout
↓re-apply every configured app's layout
← / →send window to the previous / next screen

e s d f mirror the nav layer's arrow positions, not hjkl. Not Ctrl+Alt+W for the toggle: that's Wispr Flow's dictation trigger. Not Ctrl+Down/Up for anything here: macOS reserves those for App Exposé / Mission Control.
