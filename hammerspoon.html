Resize — Ctrl+e s d f (Hammerspoon, ~/.hammerspoon/windows-position.lua)

Same physical positions as the nav layer's arrows (e=up, s=left, d=down, f=right), not literal hjkl or arrow keys.

Ctrl+Ssnap left, repeat to cycle width 1/2 → 1/3 → 2/3
Ctrl+Fsnap right, same cycle
Ctrl+Esnap top, repeat to cycle height 1/2 → 1/3 → 2/3
Ctrl+Dsnap bottom, same cycle
Ctrl+S + Ctrl+F heldfull width
Ctrl+E + Ctrl+D heldfull height
Ctrl+Gcenter, repeat to cycle size 100% → 75% → 50%

Maximize on layout — Ctrl+Alt+d / e

Acts on a fixed app list: Claude, VS Code, Notion, Cursor, Edge, Chrome, Brave, Firefox Dev Edition — maximized in place, never moved to a different screen.

Ctrl+Alt+Dre-maximize the focused app only (no-op if it isn't in the list)
Ctrl+Alt+Ere-maximize every app in the list
monitor plug/unplugsame as Ctrl+Alt+E, fires ~2s after the screen settles

Not Ctrl+Down/Ctrl+Up: macOS owns those (App Exposé / Mission Control) and swallows them before Hammerspoon sees the event.

Move to other screen — Ctrl+Alt+G

One key toggles since there are only 2 screens.

Ctrl+Alt+Gsend focused window to the other screen
